PRINCE® Devo ALL FLEET SAE 15W-40 CG-4

PRINCE® Devo ALL FLEET SAE 15W-40 CG-4 is formulated with carefully chosen mineral base stocks and a balanced additive package to provide reliable protection in conventional heavy-duty engines. Its effective detergent-dispersant chemistry controls soot accumulation, deposits and sludge formation, while outstanding TBN reserves neutralize acidic combustion by-products. Its robust formulation provides dependable protection against abrasive wear, scoring, scuffing, pitting, corrosion, and foam formation, ensuring consistent lubrication performance even under long drain interval conditions.

Intended Applications

Designed for mixed commercial fleets and older-generation diesel engines without advanced emission control systems, including trucks, buses, tractors, construction equipment and industrial diesel engines requiring API CF-4, CG-4 or compatible earlier API categories, as well as gasoline engines specifying API SJ standard.
